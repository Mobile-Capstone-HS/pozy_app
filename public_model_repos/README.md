# A-CUT Public Model Repositories

This directory contains public-facing model documentation and lightweight artifacts for the A-CUT capstone project.

Included model folders:

- `acut-nima-mobile`
- `acut-rgnet-mobile`
- `acut-mobile-alamp`
- `acut-koniq-flive-technical-iqa`

These folders document the selected A-CUT aesthetic and technical scoring models.

Large datasets, raw images, checkpoints, virtual environments, temporary logs, and large model binaries are intentionally excluded.
